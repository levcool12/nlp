
# Natural Language Processing (NLP) Course Work

This repository contains seminar tasks and laboratory assignments completed as part of my Natural Language Processing course.

## 📁 Repository Structure

* **`tasks/`** — Jupyter Notebooks (`.ipynb`) and files from hands-on seminar tasks.
* **`labs/`** — Comprehensive laboratory assignments and project implementations.

## 🛠️ Tech Stack & Tools

* **Language:** Python 3.x
* **Core Libraries:** Jupyter Notebook / Lab, NumPy, Pandas
* **NLP Libraries:** *(e.g., NLTK, spaCy, Hugging Face Transformers, Scikit-learn — add or remove based on your course)*

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/levcool12/nlp
   cd nlp
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Or specify: Open the `.ipynb` files directly in Google Colab or VS Code)*

3. **Run a seminar notebook:**
   ```bash
   jupyter notebook tasks/seminar_01.ipynb
   ```
